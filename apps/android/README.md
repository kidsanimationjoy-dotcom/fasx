# FASX Android Client

Target: Android phone controller, initially designed around Kotlin and Jetpack Compose.

Planned screens:
- Device list and pairing.
- SmartDeck home.
- Remote desktop viewer.
- Touchpad and keyboard.
- File Bridge.
- PC Health.
- Security Shield and active-session permissions.

The Android project scaffold will be added after the shared pairing/protocol contract is validated. Do not create a mock connection that appears to control a real laptop.

Google Compose documentation: https://developer.android.com/develop/ui/compose
